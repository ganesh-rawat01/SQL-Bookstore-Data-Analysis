SQL Bookstore Data Analysis

Project Overview

This project focuses on analyzing bookstore data using PostgreSQL. It explores books, customers, and orders to generate useful business insights through SQL queries.

Database Tables

- Books: Stores book details such as title, author, genre, price, and stock.
- Customers: Stores customer information such as name, email, city, and country.
- Orders: Stores order details, quantities, dates, and total amounts.

SQL Concepts Used

- SELECT, WHERE, ORDER BY
- Aggregate Functions (SUM, AVG, COUNT)
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- DISTINCT and COALESCE
- Subqueries and filtering

Analysis Performed

- Identified the most expensive and lowest-stock books.
- Calculated total revenue and books sold by genre.
- Analyzed customer orders and spending.
- Identified frequently ordered books.
- Calculated remaining book inventory.

Tools Used

- PostgreSQL
- pgAdmin 4
- SQL

How to Run

1. Install PostgreSQL and pgAdmin 4.
2. Create a database.
3. Open Query Tool in pgAdmin 4.
4. Run the SQL script provided in this repository.
